# ♟️ Neo Chess v1.0.0 — Production Release

Welcome to the initial official release of **Neo Chess App**, a full-stack, real-time multiplayer chess platform featuring interactive web view capabilities, live WebSocket game engine support, and Firebase integration.

---

## 🚀 What's New in This Release

### 🎮 Core Gameplay & Engine
* **Interactive Chess Board UI:** Clean, responsive, and intuitive chessboard interface.
* **Real-Time Multiplayer Support:** Powered by a WebSocket server (`neo-chess-server`) enabling smooth player-vs-player matchmaking and low-latency move synchronizations.
* **Smart Validation & Game Rules:** Enforces standard chess movement logic, check/checkmate detection, and turn enforcement.

### ⚡ Full-Stack Integration
* **Hybrid Mobile Architecture:** Native Android wrapper embedding web engine assets (`app/src/main/assets`).
* **Node.js WebSocket Backend:** Dedicated backend service managing game rooms, socket connections, and move broadcasting (`neo-chess-server`).
* **Firebase Services Integration:** Configured with Google Services (`google-services.json`) for user identification and telemetry tracking.

---

## 🛠️ Tech Stack Included

* **Frontend:** HTML5, CSS3, JavaScript (Embedded Web View)
* **Mobile Client:** Android Native (Java/Kotlin)
* **Backend:** Node.js, Express.js, WebSocket (`ws`)
* **Database & Auth:** Firebase Services
